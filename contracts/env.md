# Environment variables (blueprint 9.15, frozen)

Names, purposes and owners only. No value appears here, in any tracked file, in the run notes, in evidence, in the Report or in a commit message; example env files list every name with a placeholder and no value; gitleaks runs on every push. Secrets move by shell redirection only (ADR-012): a foundation helper script pipes one named key from the gitignored root env file into a CLI's stdin (`vercel env add`, `gh secret set`) with stdout and stderr sent to a log nobody reads, and dotenv loading inside scripts, tests and the harness does the rest. No model thread ever reads, prints, searches, copies or echoes an env file or a secret value; the control-plane hook denies the attempt.
